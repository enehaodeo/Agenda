# 日程 · 手工排程

一个纯本地的日程表 App。宣纸朱砂配色，无需安装、无需联网、无账号，数据只存在你自己的浏览器里。

## 怎么打开

双击 `index.html` 即可（推荐 Chrome / Edge）。

如果想用本地服务器打开（数据存储更稳妥，也便于手机在同一 Wi-Fi 下访问），双击 `启动.cmd`，浏览器会自动打开 <http://localhost:5177>。

## 六件事怎么做

| 功能 | 操作 |
|---|---|
| **① 添加任务** | 左上角写名称 → 填时／分（或点 15/30/45/60/90 快捷键）→ 选标签 → `添加到待办`。回车也能提交。事后点任务上的 `✎` 随时改名称、耗时、标签、备注。 |
| **② 拆分任务** | 打开任意任务的 `✎`，在「拆分为子任务」里 `＋ 添加子任务`，每条子任务各有自己的耗时和标签。右上角实时显示「合计 / 计划 · 剩余或超出」。拆分后父任务变成一个分组，改为分别安排各子任务。 |
| **③ 选取可用时间** | 右侧 `＋ 时间段` 填起止时间（精确到分钟），或用「上午／下午／晚间／全天」预设；也可以**直接在时间轴空白处按住鼠标上下拖动**刷出一段。拖时间段的上下边缘可以拉伸，`×` 删除。`沿用昨日` 一键复制前一天。 |
| **④ 放入日程表** | 把左侧任务**拖进时间轴**——会自动吸附到 5 分钟刻度、时间段边界和相邻色块边缘，且不会重叠、不会越出可用时间。嫌麻烦就点任务上的 `↳` 自动排入最近空档，或点 `自动排程` 一次性铺满。已排的色块还能继续拖动改时间。 |
| **⑤ 本日日程** | 打开就是今天：顶部显示当日日期与实时走秒的时钟，时间轴上有一条跟着走的朱砂色「此刻」线。`‹ ›` 或点日期可翻到别的日子，`今天` 一键回来。 |
| **⑥ 完成 / 未完成** | 色块上的 `✓`＝完成，任务从系统里删除并记入左下「已完成」；`↩`＝未完成，退回待办等你重新分配。右上角 `结算` 会集中列出所有**已经过时**的日程（按钮上带红色角标），逐条选择完成／未完成／顺延到今天最近的空档。 |

## 其他

- **撤销**：`Ctrl+Z` 或点右上角「撤销」。删除、完成、清空、自动排程等都可以回退。
- **快捷键**：`N` 聚焦新建框，`T` 回到今天，`←` `→` 翻天。
- **备份**：右上角 `导出` 存一份 JSON，`导入` 恢复。换电脑或清浏览器缓存前记得导出。
- **数据位置**：浏览器 localStorage，键名 `agenda.v1`。换浏览器 = 换一套数据。
- **完全离线**：打开时 **0 个外部请求**，不联网、不依赖任何 CDN。拉丁字体（Fraunces 标题、IBM Plex Mono 数字，仅 latin 子集共 95 KB）内嵌在 `fonts.css` 里，`file://` 双击打开也不会被 CORS 拦；中文用系统已装的 Noto Serif SC / Noto Sans SC，没装的机器依次回落到思源宋体、宋体、微软雅黑。

## 文件

```
index.html    页面结构
fonts.css     本地字体（内嵌 data URI，127 KB）
styles.css    样式（宣纸朱砂主题、配色变量都在文件顶部 :root 里）
app.js        全部逻辑：数据模型、排程算法、拖拽交互
fonts/        字体原始 woff2，仅作留档，页面不引用
启动.cmd      用 Python 起一个本地服务器并打开浏览器
```
